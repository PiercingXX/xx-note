XX-Note

The notes app that saves nothing but Markdown. Keep's front end — card grid, one-tap capture, checklists, labels, archive — over a folder of .md files on your own Synology, reached over Tailscale. Delete the app and lose nothing.

AMOLED black one host · no third party vault is truth Pixel 9 Pro · GrapheneOS · SDK 37 Compose

01 · The sync table

First match wins, and no row can lose you text

Evaluated per note by a pure function over three snapshots — what the server had at the last agreement, what the phone has now, what the server has now. No Android imports, no clocks, no timestamps.

The invariant, tested as a property over every row: no verdict reduces the bytes you can still open. Deletes become trash, conflicts become two visible notes, every ambiguity resolves toward more text. There is no timestamp-based resolution anywhere in the app — not as a fallback, not as a setting — because “newest wins” is how sync engines lose an afternoon of writing without telling anyone.

02 · The storage format

One note is one file, and that is the whole schema

The filename is cosmetic. Identity is the id, so a note renamed in Obsidian is still the same note.

Obsidian reads it already

Labels land as tags, attachments resolve as relative links, and the vault opens with no import step. Interop is inherited, not built.

Unknown keys survive

XX-Note owns eight frontmatter keys and rewrites nothing else byte-for-byte. A plugin's metadata is preserved through every save.

Attachments can't conflict

Content-addressed by SHA-256, so they are immutable. The binary sync problem collapses to “does it exist over there.” Dedup is free.

Malformed YAML is body text

Never discarded, never silently “repaired.” The note still opens; the sync screen flags it. A parser bug must not eat a note.

04 · The claim

This is the one app in the family that needs the network

The rest of the family ships with no INTERNET permission and invites you to check the manifest. XX-Note cannot, and says so.

One host

An interceptor throws on any host but the configured one. Not logs, not warns, not falls back. Its tests include the same host on another port, a redirect to a third party, and an IP literal.

No cleartext, no bypass

A network security config naming exactly one domain, cleartext forbidden. There is no “trust anyway” affordance anywhere in the app for a bad certificate.

Zero storage permissions

The mirror lives in filesDir/vault — app-private, no grant, no Storage Scopes interaction. Four permissions total, and the short list is the claim.

Revocable, and it degrades

Turn the Network permission off on GrapheneOS and you have a fully working local notes app that tells you nothing is leaving the device. Not an error. A state.
